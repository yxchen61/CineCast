# 极光视界（CineCast）音乐模块部署与音源导入手册

> **适用版本**：v1.3.0 及以上（Android & iOS 双端）  
> **配套源码仓库**：`CineCast-Repo`（`android/` + `ios/`）

---

## 1. 本地编译打包与真机部署

### 1.1 Android 编译与测试（PowerShell）

```powershell
cd d:\AI\VedioAndRead\CineCast-Repo\android
$env:JAVA_HOME = "D:\Program Files\JetBrains\IntelliJ IDEA 2025.1.3\jbr"

# 运行全量单元测试（影视 2 项 + 小说 4 项 + 音乐 3 项，共 9 项）并编译 Release APK
```

> 如本机已安装本地 Gradle 8.11.1，也可直接调用 `gradle testDebugUnitTest assembleRelease --no-daemon`。

**安装包位置**：
- 本地编译归档：`releases/极光视界-CineCast-v1.3.0-release.apk`
- GitHub Actions 自动构建：推送 `v1.3.0` 标签后，可在 GitHub 仓库 **Releases (`v1.3.0`)** 或 **Actions** 页面下载 Android APK 与 iOS IPA。

## 2. GitHub 开源音乐源导入指南

所有音乐源管理均独立位于底部导航 **「音乐」→ 顶部分段栏「音乐源」**，与影视源、小说书源完全分离。

### 2.1 一键拉取预设 GitHub / Gitee 音乐源

进入 **「音乐 → 音乐源」**，顶部卡片预置了 3 条开源订阅地址，点击标签填入后点击 **「从 Git 拉取导入」**：

| 预置订阅名称 | 订阅地址 | 格式说明 |
| :--- | :--- | :--- |
| **Huibq MusicFree 聚合源 (CDN)** | `https://fastly.jsdelivr.net/gh/Huibq/keep-alive/Music_Free/myPlugins.json` | MusicFree `plugins.json`（自动映射主流音源） |
| **MusicFree 官方插件源 (Gitee)** | `https://gitee.com/maotoumao/MusicFreePlugins/raw/master/plugins.json` | 国内 Gitee 镜像，直连稳定 |
| **CineCast 开源音乐源模板** | `https://fastly.jsdelivr.net/gh/yxchen61/CineCast@main/docs/%E7%A4%BA%E4%BE%8B%E9%9F%B3%E4%B9%90%E6%BA%90%E9%85%8D%E7%BD%AE_CineCast%E6%A8%A1%E6%9D%BF.json` | 标准 CineCast 多协议音乐源数组 |

### 2.2 导入自建 Meting / GDStudio / M3U 电台源

1. **粘贴 JSON / M3U**：复制 [示例音乐源配置_CineCast模板.json](示例音乐源配置_CineCast模板.json) 或任意 `.m3u` 音乐电台内容，点击 **「粘贴 JSON」** 一键解析。
2. **手动新增自定义源**：点击 **「自定义音源」**，选择协议类型（`Meting API` / `GDStudio API` / `Audius` / `Radio-Browser` / `M3U`），填写自建部署地址即可接入（例如自己通过 Docker 部署的 `injahow/meting-api` 或 `metowolf/Meting-API`）。

## 3. 音乐播放与歌单使用说明

1. **榜单发现与跨源搜歌**：在「音乐馆」可切换不同音乐源和榜单；点击右上角搜索按钮默认开启 **「全音乐源聚合搜索」**，实时并发聚合多个开源曲库结果。
2. **迷你条与全屏同步歌词**：播放歌曲后底部常驻迷你控制条；点击展开全屏播放器，可切换 **「同步歌词」** 并点击任意一行歌词精准跳转进度。
3. **播放中一键换源**：若遇到某曲版权受限或音频流超时，点击播放器右上角 **「换源」**，系统自动在其余音乐源中并发检索同名歌曲，一键切换试听。
4. **独立备份与恢复**：在 **「音乐 → 音乐源」** 点击 **「导出音源」** / **「恢复」**，可单独备份和迁移音乐源、我喜欢的音乐与自建歌单。
