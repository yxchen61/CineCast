# 极光视界（CineCast）开发编译与真机调试部署手册

本文档面向开发者与高级用户，详细说明项目源码结构、环境依赖、Gradle 命令行编译、ADB 真机安装调试以及二次开发扩展方法。

---

## 1. 开发环境要求

- **操作系统**：Windows 10 / 11、macOS 或 Linux
- **JDK**：OpenJDK 17 或 OpenJDK 21（本项目编译实测采用 OpenJDK 21.0.7）
- **Android SDK**：
  - `compileSdk = 35`（Android 15）
  - `build-tools = 35.0.0`
  - `platform-tools`（含 `adb`）
  - `minSdk = 24`（兼容 Android 7.0 及以上所有设备）
- **核心依赖版本**：
  - Android Gradle Plugin `8.7.3` + Gradle `8.11.1`
  - Kotlin `2.0.21` + Compose Compiler Plugin
  - Jetpack Compose BOM `2024.12.01`（Material 3 + Material Icons Extended）
  - AndroidX Media3 `1.5.1`（ExoPlayer + HLS + DASH + OkHttpDataSource）
  - OkHttp `4.12.0`、Coil Compose `2.7.0`、Kotlinx Serialization `1.7.3`

## 3. 命令行编译与测试

在项目根目录 `CineCast/` 中执行以下 PowerShell 命令：

### 3.1 运行单元测试
```powershell
$env:JAVA_HOME = "D:\Program Files\JetBrains\IntelliJ IDEA 2025.1.3\jbr"
.\gradlew.bat testDebugUnitTest
```

### 3.2 编译 Debug / Release 安装包（APK）
```powershell
# 编译调试版 APK
.\gradlew.bat assembleDebug

# 编译正式发布版 APK（已配置内置签名可直接侧载安装）
.\gradlew.bat assembleRelease
```
输出文件路径：
- Debug APK：`app/build/outputs/apk/debug/app-debug.apk`
- Release APK：`app/build/outputs/apk/release/app-release.apk`

## 4. 真机安装与 ADB 调试指南

### 4.1 手机端开启 USB 调试
1. 打开手机 **「设置」->「关于手机」**，连续点击 **「版本号 / MIUI 版本 / HarmonyOS 版本」** 7 次激活开发者模式。
2. 返回 **「设置」->「系统和更新 / 更多设置」->「开发者选项」**。
3. 打开 **「USB 调试」**（小米手机请同时打开 **「USB 安装」** 和 **「USB 调试（安全设置）」**）。
4. 用支持数据传输的 USB 线连接电脑，手机弹窗询问“允许 USB 调试吗？”时勾选 **一律允许** 并点击 **允许**。

> **无线调试方式（Android 11+ 免数据线）**：
> 在开发者选项中开启 **「无线调试」**，点击「使用配对码配对设备」，在电脑运行：
> ```powershell
> adb pair <手机IP>:<配对端口>
> adb connect <手机IP>:<调试端口>
> ```

### 4.2 常用 ADB 安装与调试命令
```powershell
# 1. 检查已连接手机
adb devices -l

# 2. 安装或覆盖更新 APK（-r 保留数据，-t 允许测试包）
adb install -r "E:\视频软件\极光视界-CineCast-v1.0.0-release.apk"

# 3. 启动极光视界 App
adb shell am start -n com.cinecast.app/.MainActivity

# 4. 实时查看应用运行与崩溃日志（过滤本应用进程）
adb logcat -s AndroidRuntime:E ExoPlayerImpl:W System.err:W

# 5. 检查网络请求与 DLNA 投屏运行状态
adb logcat | Select-String "cinecast|ExoPlayer|MediaCodec"

# 6. 卸载应用
adb uninstall com.cinecast.app
```

## 5. 二次开发扩展建议

1. **新增自定义视频源协议**：在 `Models.kt` 的 `SourceType` 中新增枚举，并在 `VodSourceEngine.kt` 的 `when (source.type)` 分支中实现 `fetchVodList` / `search` / `fetchDetail` 即可无缝接入现有 UI。
2. **自定义正式签名 Keystore**：如需上架应用商店，可使用 `keytool` 生成个人 `.jks` 签名证书并在 `app/build.gradle.kts` 的 `signingConfigs` 中配置 `release` 签名。
3. **升级为离线本地数据库（Room）**：当前采用 `AppRepository` JSON 持久化以保证零 KSP 编译复杂度和便捷的导入导出；如需支持数万条离线片库缓存，可平滑替换为 Room 数据库。
