# 极光视界（CineCast）小说阅读模块部署与书源导入手册

> **适用版本**：v1.2.0 及以上（Android & iOS 双端）  
> **配套源码仓库**：`CineCast-Repo`（`android/` + `ios/`）

---

## 1. 环境准备与本地编译打包

### 1.1 Android 端本地编译与生成 APK 安装包

**环境依赖**：
- **JDK**：OpenJDK 17 或 21（本地实测使用 OpenJDK 21.0.7）
- **Android SDK**：`compileSdk = 35`、`build-tools = 35.0.0`、`minSdk = 24`（兼容 Android 7.0+ 及鸿蒙 HarmonyOS 2~4.x）
- **新增核心依赖**：`org.jsoup:jsoup:1.18.3`（HTML/CSS 规则解析，已在 `android/app/build.gradle.kts` 中配置，并配置了 Aliyun Maven 镜像加速）

**编译与单元测试命令（PowerShell）**：
```powershell
# 1. 进入 Android 工程目录
cd d:\AI\VedioAndRead\CineCast-Repo\android

# 2. 确认 local.properties 指向本机 Android SDK（示例）
# sdk.dir=C\:\\Users\\<用户名>\\AppData\\Local\\Android\\Sdk

# 3. 指定 JDK 17/21
$env:JAVA_HOME = "D:\Program Files\JetBrains\IntelliJ IDEA 2025.1.3\jbr"

# 4. 运行全部单元测试（含视频解析测试 + 小说 Legado 规则引擎测试）并编译正式版 APK
.\gradlew.bat testDebugUnitTest assembleRelease --no-daemon
```

> **提示**：如遇到本机网络下载 `gradle-8.11.1-bin.zip` 缓慢，可直接使用已安装的本地 Gradle 8.11.1 执行 `gradle testDebugUnitTest assembleRelease --no-daemon`。

**安装包输出位置**：
- 正式版可直装 APK：`android/app/build/outputs/apk/release/app-release.apk`
- 本仓库同步归档安装包：`releases/极光视界-CineCast-v1.2.0-release.apk`

### 1.2 真机安装部署（ADB / 直接传输）

1. **直接手机安装**：将 `releases/极光视界-CineCast-v1.2.0-release.apk` 发送至手机，点击安装即可（已内置签名，可直接覆盖升级 v1.1.1 且保留原有视频源数据）。
2. **ADB 命令行部署**：
   ```powershell
   adb devices -l
   adb install -r "d:\AI\VedioAndRead\CineCast-Repo\releases\极光视界-CineCast-v1.2.0-release.apk"
   adb shell am start -n com.cinecast.app/.MainActivity
   ```

### 1.3 iOS 端构建与 GitHub Actions 自动化部署

每次推送代码至 GitHub `main` 分支或打 `v*` 标签后，GitHub Actions 会自动触发两条流水线：
- **Build CineCast Android APK**（`.github/workflows/build-android-apk.yml`）：自动运行单元测试并产出 `CineCast-Android-v1.2.0-APK`（含 Release & Debug APK）。
- **Build CineCast iOS IPA**（`.github/workflows/build-ios-ipa.yml`）：在 `macos-15` Runner 上通过 `xcodegen generate` 自动生成工程并编译 `CineCast-iOS-v1.2.0-Signed-IPA`（配置签名 Secrets 后）或 `Unsigned-IPA`。

macOS 本地构建命令：
```bash
cd ios
brew install xcodegen
xcodegen generate
open CineCast.xcodeproj
```

## 2. GitHub 开源小说书源导入指南

小说模块的书源管理位于底部导航 **「阅读」→ 顶部分段栏「书源」**，与底部的「影视源」完全独立。

### 2.1 一键拉取内置 GitHub 开源书源仓库（推荐）

进入 **「阅读 → 书源」**，顶部蓝色卡片已预置 4 个开源书源仓库的 jsDelivr 国内加速订阅标签，点击标签填入地址后点击 **「从 Git 拉取导入」** 即可自动解析去重并过滤不可用的纯 JS/音频源：

| 仓库名称 | 推荐 CDN 加速订阅地址 | 收录特点 |
| :--- | :--- | :--- |
| **XIU2/Yuedu 精选书源** | `https://fastly.jsdelivr.net/gh/XIU2/Yuedu@master/shuyuan` | 精品少而精，含酷我 API、速读谷、手机小说等 |
| **liufuyou/read Yiove** | `https://fastly.jsdelivr.net/gh/liufuyou/read@main/sources/yiove-novel.json` | 持续清洗去重的综合中文/轻小说/英文书源 |
| **liufuyou/read YCK** | `https://fastly.jsdelivr.net/gh/liufuyou/read@main/sources/yck-novel.json` | 覆盖面广的大全集书源 |
| **openrepos 通用书源** | `https://fastly.jsdelivr.net/gh/openrepos/booksource@main/yuedu.json` | 经典 Legado 3.0 通用规则合集 |

> **国内网络加速小技巧**：如果你在 GitHub 找到了其他书源的 `raw.githubusercontent.com/<用户>/<仓库>/<分支>/<路径>` 链接但拉取超时，可将其替换为：
> `https://fastly.jsdelivr.net/gh/<用户>/<仓库>@<分支>/<路径>`

### 2.2 本地粘贴 Legado JSON 导入

1. 打开本仓库提供的模板文件 [示例小说书源配置_Legado模板.json](示例小说书源配置_Legado模板.json) 或任意 Legado `.json` 文件，复制全文。
2. 在 App 内进入 **「阅读 → 书源」**，点击 **「粘贴 JSON」**，粘贴内容后点击 **「解析导入」**。

### 2.3 手动添加自定义书源

点击 **「自定义书源」** 按钮，填写以下核心字段即可接入任意新小说站：

| 字段 | 说明 | JSON API 示例 | HTML 网页示例 |
| :--- | :--- | :--- | :--- |
| **站点根地址** | 网站域名 | `http://appi.kuwo.cn` | `https://www.sudugu.co` |
| **搜索 URL 模板** | `{{key}}` 代表关键词，`{{page}}` 代表页码 | `/novels/api/book/search?keyword={{key}}&pi={{page}}` | `/search?q={{key}}` 或 POST 选项 |
| **搜索列表规则** | 定位单本书条目 | `$.data` | `class.item` 或 `.bk` |
| **书名规则** | 从条目提取书名 | `$.title` | `tag.h3.0@tag.a.0@text` |
| **详情链接规则** | 从条目提取书籍 URL | `/novels/api/book/{{$.book_id}}` | `tag.a.0@href` |
| **目录列表规则** | 定位章节列表 | `$.data` | `id.list.0@tag.a` |
| **正文规则** | 提取章节内容 | `$.data.content` | `class.con.0@html` |

## 3. 阅读功能使用指南

1. **书架断点续读**：点击任何书籍开始阅读后将自动加入书架并实时保存阅读章节，顶部大圆角「继续阅读」卡片支持一键回到上次章节。
2. **多书源并发搜书**：点击「阅读」页右上角搜索图标，默认开启 **「全书源聚合搜索」**，并发请求最多 10 个已启用书源并实时流式展示匹配结果。
3. **沉浸式阅读器操作**：
   - 点击屏幕中央：唤出 / 隐藏顶部与底部控制栏。
   - **排版主题**：内置「纯净纸白」「暖黄羊皮」「护眼豆沙」「深邃暗夜」4 套 Google 护眼主题，支持无级调节字号（14~28sp）、行距（1.4~2.2x）以及切换印刷衬线体（Serif）。
   - **目录与进度条**：支持正/倒序目录切换与底部进度条快速拖拽跳章。
   - **在线一键换源**：若某书源章节失效、缺章或加载缓慢，点击阅读器右上角 **「换源」**，系统自动在其余书源中并发匹配同名小说，点击即可保留当前章节进度无缝切换。
4. **独立书源与书架备份**：在 **「阅读 → 书源」** 页面点击 **「导出书源」** / **「恢复」**，可通过剪贴板在多台 Android / iOS 设备间同步小说书源与书架，不影响视频配置。

## 4. 常见问题排查

| 现象 | 原因 | 解决方法 |
| :--- | :--- | :--- |
| 导入 GitHub 书源时提示超时 | `raw.githubusercontent.com` 直连不稳定 | 使用内置的 `fastly.jsdelivr.net/gh/...` CDN 加速链接，或下载 JSON 后使用「粘贴 JSON」导入 |
| 导入后显示“跳过纯 JS 条目” | 部分网站依赖 Cloudflare 验证码或复杂 JS 加密 | 正常现象，解析器已自动过滤不可直连规则，保留所有可直接解析的高速书源 |
| 个别站点书城或正文加载失败 | 站点临时波动或更换域名 | 在「书源」页点击 **「测速」** 排查并关闭超时源；阅读时直接点右上角 **「换源」** 切换至酷我 API 或其他可用源 |
| 中文内容出现乱码 | 老旧站点采用 GBK/GB2312 编码 | 引擎已支持自动探测响应头与 `<meta charset>`，如需强制指定可在 `searchUrl` 选项中添加 `{"charset":"gbk"}` |
