# 极光视界（CineCast）用户使用与视频源配置指南

欢迎使用 **极光视界（CineCast）**！本指南将帮助您快速完成安装、配置各类视频源、播放高清视频以及投屏到电视大屏。

---

## 1. 安装方法

1. 将安装包 `极光视界-CineCast-v1.0.0-release.apk` 传输到您的 Android 手机（或通过电脑 USB 连接使用 ADB 一键安装）。
2. 在手机文件管理器中点击 APK 文件。
3. 如系统提示“禁止安装未知来源应用”，请在弹窗中开启“允许安装此来源应用”，点击**安装**即可。
4. 安装完成后，桌面会出现蓝白播放投屏图标 **「极光视界」**。

---

## 2. 快速上手：4 大核心页面

### 2.1 发现页（首页）
- **切换视频源**：点击顶部搜索栏下方的视频源胶囊按钮，即可在已启用的直连高清源之间一键切换，或直接打开网页嗅探站点。
- **分类筛选**：横向滑动分类标签（电影、连续剧、动漫、综艺、纪录片等），支持下拉滚动自动加载下一页。
- **全源聚合搜索**：点击顶部 Google 风格搜索栏，输入片名、剧名或演员。默认开启 **「全源聚合搜索」**，一次搜索并发查询多个高清视频源；也可切换为「仅当前源」。

### 2.2 影视源配置页（核心亮点）
本应用支持 4 种方式接入任意视频源：

#### 方式 A：一键导入 TVBox 订阅配置（参考 `cyao2q/files`）
1. 进入底部 **「影视源」** 标签页。
2. 在顶部蓝色「导入 TVBox 配置订阅」卡片中，直接点击预设标签：
   - `cyao2q/files 主配置 (m.json)`：`https://cyao2q.github.io/files/m.json`
   - `cyao2q/files 扩展配置 (xs.json)`：`https://cyao2q.github.io/files/xs.json`
   - 或输入您自己收集的任意 TVBox JSON 订阅链接。
3. 点击 **「拉取并导入配置」**，应用会自动导入其中的：
   - 可直连播放的视频资源站（Type 0/1/4）
   - 电视直播源（`lives`）
   - VIP 网页解析接口（`parses`）
   - 广告域名屏蔽规则（`ads`）

#### 方式 B：粘贴 JSON 导入
点击顶部右上角粘贴图标或「粘贴 JSON」按钮，可将本地编辑好的 TVBox JSON 文本直接粘贴导入。

#### 方式 C：手动添加单个视频源 / 任意视频网站
点击右下角 **「+ 添加视频源」** 按钮：
- **苹果 CMS JSON 接口（推荐）**：填写标准资源站采集接口，例如 `https://cj.ffzyapi.com/api.php/provide/vod/`
- **苹果 CMS XML 接口**：填写 XML 采集接口，例如 `https://cj.ffzyapi.com/api.php/provide/vod/at/xml/`
- **TVBox T4 远程接口**：填写标准 T4 服务 URL
- **网页嗅探视频站（支持任意视频网站！）**：填写任意影视网站首页 URL（例如 `https://m.bilibili.com/` 或任意自建影视站点），保存后即可通过内置嗅探浏览器打开！

#### 方式 D：源测速与启停管理
- 每个源卡片均提供 **「测速」** 按钮，可一键检测接口响应耗时（毫秒 ms）与连通状态。
- 通过右侧开关可随时启用/停用某个源，或点击「编辑」「删除」维护列表。

## 3. 任意视频网站网页嗅探与解析教程

如果您想观看某个没有开放 API 的视频网站，或主流平台页面：
1. 在「发现页」搜索栏右侧点击地球图标 🌐，或在「影视源」中对网页嗅探站点点击 **「打开嗅探」**。
2. 在顶部地址栏输入任意视频网站网址并打开目标视频播放页。
3. **自动抓流**：页面开始加载视频后，内置嗅探器会自动过滤广告并抓取 `.m3u8` / `.mp4` 高清流；右下角会弹出蓝色按钮 **「已嗅探 N 条高清流」**。
4. **使用 VIP 解析接口**：如遇网页加密或需解析，点击顶部右上角 **魔法棒图标 ✨**，选择从 `cyao2q/files` 导入的解析线路（如 `xmflv`、`pouyun` 等），页面重新加载后即可嗅探出高清流。
5. 点击右下角嗅探按钮，选择一条高清流即可直接跳转至 **原生 Media3 高清播放器** 播放或 **一键投屏到电视**！

## 4. 高清播放器手势与功能操作

| 操作方式 | 对应功能 |
| :--- | :--- |
| **单击屏幕** | 显示 / 隐藏播放控制栏 |
| **双击屏幕** | 播放 / 暂停 |
| **横向左右滑动** | 精准快进 / 快退（屏幕中央显示目标时间预览） |
| **屏幕左侧上下滑动** | 调节画面亮度 |
| **屏幕右侧上下滑动** | 调节媒体音量 |
| **顶部高清角标** | 自动识别并显示当前流实际画质（`4K` / `2K` / `1080P` / `720P`） |
| **顶部画中画图标** | 开启 Android 系统小窗悬浮播放（支持边聊天边看剧） |
| **底部倍速 / 比例** | 支持 `0.5x ~ 3.0x` 倍速与 `适应 / 铺满 / 拉伸` 画面比例切换 |
| **切换线路与选集** | 竖屏播放页下方可切换播放线路（优先推荐 `m3u8` 线路）与选集，支持自动连播下一集及断点续播 |

## 5. 电视投屏（DLNA）使用说明

### 5.1 使用 DLNA 投屏（推荐，手机可息屏）
1. 确保 **手机** 与 **智能电视 / 电视盒子** 连接在 **同一个 Wi-Fi 局域网** 下（避免一方连 5G 访客网络或开启 AP 隔离）。
2. 在电视端确认投屏服务已开启（多数品牌电视默认开启，也可在电视安装并打开「乐播投屏」等接收端）。
3. 在手机播放页点击右上角 **投屏图标 📺**（或详情页「DLNA 投屏」按钮）。
4. 在弹出的 Material 3 投屏面板中等待 2~5 秒扫描，点击您的电视名称即可立即开始大屏高清播放！
5. 连接成功后，可在投屏面板中使用 **手机遥控器**：远程播放/暂停、快进/快退、拖拽进度条、调节电视音量、退出投屏。

### 5.2 备用投屏方式
如果电视不支持 DLNA，投屏面板底部还提供两个实用按钮：
- **系统无线投屏（Miracast）**：一键跳转手机系统无线投屏设置进行整机镜像。
- **外部播放器**：一键调用手机已安装的 MX Player / VLC / 第三方投屏工具播放当前高清流。

## 6. 常见问题排查（FAQ）

1. **Q：导入 `cyao2q/files/m.json` 后，为什么部分站点显示「Spider」且默认未启用？**
   - A：`m.json` 中的 `type: 3` 站点依赖 TVBox 专用闭源 JAR 爬虫运行环境。极光视界默认自动启用所有可直连高清源（Type 0/1/4）、直播源（`lives`）、解析接口（`parses`）和广告规则（`ads`）；您也可以随时在「影视源」中添加更多苹果 CMS 直连源或使用「网页嗅探」观看任意网站。
2. **Q：为什么某些视频播放卡顿或报错？**
   - A：不同资源站线路质量不同，请在播放页下方切换另一条 **播放线路**（优先选择带 `m3u8` 字样的线路），或在首页切换其他视频源搜索同一部影片。
3. **Q：投屏搜索不到电视怎么办？**
   - A：① 确认手机和电视在同一 Wi-Fi 路由器下；② 检查路由器是否关闭了「AP 隔离 / 客户端隔离」；③ 在电视上打开系统投屏应用或乐播投屏后，点击手机投屏面板右上角刷新按钮重新扫描。
4. **Q：如何把配置同步给家人或新手机？**
   - A：进入 **「我的」->「配置备份与恢复」**，点击「复制导出配置」发送给新手机，在新手机点击「粘贴恢复配置」即可瞬间同步所有视频源、订阅、直播源和设置！
